# understanding-check

Use this skill only after an explicit request for an understanding check, such as testing or quizzing, Socratic questioning, or Five Whys for root-cause understanding. An ordinary request for an explanation, debugging help, or root-cause work does not activate it.

## Select the mode

- Use Socratic questioning for an explicit understanding check about a general topic.
- Use Five Whys only when the explicit understanding check concerns root-cause analysis or Alan requests Five Whys to test his understanding.
- If the request does not name a method, default to Socratic questioning.

## Interaction rules

- During an active check, ask exactly one focused question in each response, then wait for Alan's answer.
- Do not reveal, correct, or teach the answer before Alan attempts it.
- Build each question from Alan's previous answer. Probe the assumptions or evidence in that answer instead of following a prewritten questionnaire.
- If Alan says to stop, stop. If he asks for the answer before attempting one, ask for his best attempt first. If he asks again after attempting, give the answer directly and end the active check.

## Socratic checks

- Begin by asking Alan to explain, predict, apply, or distinguish something about the stated topic.
- Use the answer to choose the next single question. Probe the weakest assumption, an unexplained implication, or evidence for a claim.
- Do not steer toward a predetermined sequence of questions or disclose the target answer through the question.

## Five Whys checks

- Start from the concrete failure or problem stated by Alan. If none is stated, ask one question that establishes it before tracing causes.
- Treat the causal claim in each answer as the next link in the chain. Ask one question about why that link caused the preceding problem.
- When an answer mixes evidence and assumption, ask the single question that tests the unsupported causal link before proceeding.
- Stop as soon as an actionable root cause is supported by evidence. Do not force five questions or add filler questions.

## Finish

When understanding is sufficiently demonstrated, or Alan stops or requests the answer after an attempt, give a concise assessment containing:

- what Alan understands;
- remaining gaps or untested assumptions; and
- the next concept to study.

Permit Alan to stop or, after an attempt, ask for the answer. Do not add another question to the completion assessment.
